# Alisha Joshi — Portfolio

Personal portfolio featuring Beneath the Surface, Cultural Clue, and StoryMap AI, along with education, experience, skills, a resume download, and contact links.

## Publish with GitHub Pages

1. Sign in as `jAlisha261`.
2. Create a **public** repository named `jAlisha261.github.io`. If it already exists, review its contents before replacing any files.
3. Upload this folder's **contents** to the repository root: `index.html`, `styles.css`, `app.js`, the entire `assets` folder, and `.nojekyll`. Do not upload the ZIP itself or a parent folder around the files. Commit to `main`.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**. Save.
5. Wait for GitHub to finish publishing. The intended address is `https://jalisha261.github.io/`.

No domain purchase or build command is needed. GitHub says publishing can take up to 10 minutes.

GitHub instructions: https://docs.github.com/en/pages/quickstart

## Edit

- `index.html`: main page content
- `styles.css`: appearance and responsive layouts
- `app.js`: project details and interactions
- `assets/`: screenshots, local fonts, favicon, and resume PDF

Commit changes to `main` to update the published site. The repository and its uploaded files will be public.
